# Jev decision support

Use Jev when plausible alternatives remain after gathering evidence and a semantic
judgment matters. Exact source, specifications, checks, user constraints, and
lifecycle authority retain precedence. Jev is not for exact lookups, calculations,
code/prose generation, permissions, or replacing required tests.

Supply bounded verbatim primary evidence; exclude secrets, preferred verdicts,
other agents' conclusions, and earlier Jev answers. Use the skill's official helper
in an isolated runtime. If authentication is unavailable, ask the orchestrator or
user for the environment-file path or runtime mechanism; never search for credentials.
Verify any configured API destination before sending evidence.

Record the question, model, full distribution, and effect on your decision in task
evidence. If no suitable decision arises, say so briefly; do not call merely to
prove use. This footer grants no permission to expand scope, bypass gates, or publish.
